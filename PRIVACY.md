# Privacy

LouisMahdi System Inspector is read-only and uses privacy mode by default.

The application does not automatically connect to the internet, upload reports, send telemetry, run an internet speed test, query a public IP service, download dependencies, or transmit collected information.

The GitHub profile is opened only after an explicit user click.

Standard reports redact or omit sensitive identifiers. Extended unredacted reporting requires an explicit user selection.
