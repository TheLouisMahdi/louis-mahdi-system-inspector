# Security Policy

## Reporting a vulnerability

Report security concerns through the project owner profile:

https://github.com/TheLouisMahdi

Do not include private system reports, serial numbers, MAC addresses, IP addresses, or other sensitive identifiers in a public issue.

## Application behavior

The application is read-only. It does not change the registry, firmware, TPM, Secure Boot, network configuration, storage configuration, drivers, or operating-system settings.
